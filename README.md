# SRK's Haunted House

A browser-based horror escape game built using HTML5 Canvas and JavaScript.

## Features
- Dynamic enemy AI
- Interactive puzzles
- Hidden PIN system
- Key collection
- Particle effects
- Survival gameplay

## Controls
WASD / Arrow Keys - Move
E - Interact

## Objective
Find the PIN, unlock the correct door, avoid the spirits, and escape.

## Technologies
- HTML5 Canvas
- JavaScript
- CSS
